# Skywalkingzulu1.github.io

Personal site — Investor Research Library: **52 Gauteng early-stage venture firm profiles**, outreach playbook, X-handle table, master index and sources (Doctors on Wheels campaign research).

Rendered by GitHub Pages (Jekyll/minima). Direct contact details are redacted; the full copy lives in the private `vc-research-full` repo.

## Layout
- `index.md` — home + full profile index
- `00-master-index.md`, `outreach-playbook.md`, `x-handles.md`, `sources.md` — navigation/meta pages
- `NN-*.md` — one dossier per fund (01–52)
